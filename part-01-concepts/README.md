# Part 1: What is an AI Mesh?

An agent mesh is an architectural approach, not a universal protocol.

```text
Application
    |
Coordinator
    +-- Tools (HTTP / MCP)
    +-- Independent agents (HTTP / A2A)
    +-- Model access (possibly via AI gateway)
```

A mesh may supply shared discovery, identity, connectivity, and policy when those become recurring cross-team problems. It is not required just to call two tools.
