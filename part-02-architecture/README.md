# Part 2: Choose boundaries before protocols

| Responsibility | First choice |
| --- | --- |
| Fetch latency measurements | Deterministic tool |
| Fetch deployment events | Deterministic tool |
| Coordinate evidence collection | Application coordinator |
| Analyze deployments for several teams | Independent agent, if justified |

Key questions: who owns the capability, who authorizes access, what happens on failure, and what evidence can a reviewer verify?
